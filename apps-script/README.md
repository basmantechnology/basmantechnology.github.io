# Apps Script (dev)

`JobFetcher.gs` fetches external jobs (Adzuna, Jooble, Careerjet, Greenhouse, Lever,
Remotive, RemoteOK) into an "External Jobs" review tab. Not live yet.

It is not served by the website. Copy it into the Google Apps Script project as a new file.
API keys go in Script Properties, never in this repo.
